# 🇬🇧 English A2

**British English — курс A2.** 12 недель британского английского для русскоязычных: Present Perfect, условные предложения, пассив, косвенная речь и подготовка к экзамену Cambridge A2 Key, по методу Фейнмана. Сделан по образцу [Portuguese by Feinman A2](https://github.com/vpresweb/Portuguese-by-Feinman-A2).

> Понял — объясни ребёнку. Не можешь объяснить — значит, не понял.

Онлайн: https://vpresweb.github.io/English_A2/

Предыдущий уровень — [курс A1](https://github.com/vpresweb/English_A1).

## Структура курса

| Нед. | Тема |
|:---:|---|
| 1 | Past Simple и Past Continuous |
| 2 | Present Perfect (ever, never, just, already, yet) |
| 3 | Present Perfect или Past Simple · for / since |
| 4 | Будущее: will, going to, Present Continuous |
| 5 | Модальные глаголы (can, might, should, must, have to) |
| 6 | Условия: zero и first conditional, unless |
| 7 | Second conditional и would |
| 8 | Страдательный залог (Passive) |
| 9 | Глагол + -ing или to |
| 10 | Used to и относительные предложения (who, which, where, whose) |
| 11 | Косвенная речь, связки и письмо (e-mail, история) |
| 12 | A2 Key — подготовка к экзамену |

Каждая неделя содержит разделы: 📅 План (по дням, с чек-листом) · 📖 Теория · ⚙️ Формы · 💡 Употребление · ⚖️ Сравнение · 💬 Диалог (с переводом) · 🎯 Тест · ✍️ Фейнман.

- 🔊 **Озвучка.** Нажмите на любой английский текст — пример, форму в таблице, реплику диалога, вопрос или вариант теста — и браузер произнесёт его британским голосом `en-GB`, если он есть (Web Speech API). Диалог можно прослушать целиком.
- 💾 **Прогресс.** Отметки плана, результаты тестов (прогресс по темам недели) и тексты Фейнман-объяснений сохраняются в браузере (`localStorage`). Недели с тестом от 80% отмечаются точкой.
- 🌓 **Тема.** Светлая и тёмная, переключается кнопкой «◐ Тема».
- 📱 **PWA.** На телефоне сайт можно добавить на главный экран как приложение.
- ⚡ **Без сборки и зависимостей.** Чистые HTML, CSS и JavaScript.

## Запуск

```bash
git clone https://github.com/vpresweb/English_A2.git
cd English_A2
python -m http.server 8000
# откройте http://localhost:8000
```

Можно просто открыть `index.html` двойным кликом: скрипты подключены без модулей.

## Структура файлов

```
index.html             — каркас страницы
css/styles.css         — дизайн, светлая и тёмная тема
js/core.js             — хранилище прогресса, помощники разметки, озвучка speak()
js/week-01.js … 12.js  — содержание недель (данные)
js/app.js              — сборка страниц и интерактив: план, тест, диалог, дневник, тема
tests/                 — автотесты (node --test)
```

Неделя — объект в `COURSE.weeks`: `title`, `tag`, `goal`, `days` (7 дней), `progress` (4 темы), HTML-разделы `theory`, `forms`, `usage`, `compare`, `dialog` (`[кто, английский, перевод]`), `test` (`{q, o, a, c, e}`: вопрос, варианты, верный ответ, номер темы прогресса, пояснение) и `feynman`.

## Тесты

```
npm test
```

Проверяется полнота всех недель, корректность вопросов, равномерное распределение правильных ответов, покрытие тем прогресса вопросами, диалоги и парность HTML-тегов. Тесты запускаются в GitHub Actions при каждом push в `main`.
